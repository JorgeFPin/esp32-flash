    Problemas comuns
    
      
    
        A porta COM não aparece na lista
        
      
          
    • Use um cabo USB de dados (muitos cabos só carregam).
      • 
          
    • Instale o driver do adaptador USB da placa:
            CP210x (Silicon Labs) ou
            CH340 / CH9102 (WCH).
      • 
          
    • Ative Mostrar todas as portas série em Opções avançadas.
      • 
        
    
      
    
      
    
        “Não foi possível ligar” / a placa não entra em modo de programação
        
      
          
    • Mantenha premido o botão BOOT (ou IO0), carregue e solte RESET (EN/RST), solte BOOT e tente Ligar de novo.
      • 
          
    • No ESP32-S3 com USB nativo: mantenha BOOT premido enquanto liga o cabo USB.
      • 
        
    
      
    
      
    
        “A porta está ocupada”
        
    • Feche o Arduino IDE (monitor série), outros programas de terminal e outros separadores com esta página.
    
      
    
      
    
        A gravação falha a meio
        
      
          
    • Baixe a Velocidade para 115200 e tente novamente.
      • 
          
    • Evite hubs USB; ligue diretamente ao computador.
      • 
        
    
      
    
      
    
        Depois de gravar, a placa não arranca
        
      
          
    • Carregue no botão RESET (EN/RST).
      • 
          
    • Repita a gravação com Apagar toda a flash antes de gravar ativo.
